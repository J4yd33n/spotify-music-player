# Spotify Music Player

A small Spotify-inspired static music player built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` with VS Code Live Server, or run:

```bash
python -m http.server 5500
```

Then open:

http://localhost:5500

## Deploy to Netlify

This is a static site. No build command is required.

- Build command: leave empty
- Publish directory: `.`
- Netlify can deploy directly from the GitHub repository.

## Important

The demo player controls and progress bar are functional, but the repository does not contain actual audio files. The play button therefore simulates playback progress rather than playing a song.
